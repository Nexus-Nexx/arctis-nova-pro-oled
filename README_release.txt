ARCTIS OLED — визуализатор музыки для экрана базы SteelSeries Arctis Nova Pro
=============================================================================

ЗАПУСК (Python не нужен)
1. Распакуйте папку ArctisOLED туда, где она будет жить постоянно,
   например в Документы. Не запускайте прямо из архива.
2. Запустите ArctisOLED.exe.
   Если Windows покажет «Windows защитила ваш компьютер»: «Подробнее» -> «Выполнить в любом случае».
   Программа не подписана сертификатом, поэтому SmartScreen её не знает.
3. Включите музыку — на экране базы появится спектр. Слева в окне живой предпросмотр.
4. Выберите визуализацию справа и нажмите «Применить на базу».
5. ⚙ Настройки: язык, сворачивание в трей, запуск вместе с Windows.

Закрыть окно = свернуть в трей (иконка с жёлтыми столбиками возле часов; в Windows 11
она может прятаться под стрелкой ^). Полный выход: правый клик по иконке -> Выход.
Экран базы при этом продолжает работать; остановить его: кнопка «Остановить»
в окне или пункт в меню трея.

Не работает? Запустите ArctisOLED.exe --diag и приложите созданный diag.txt к issue:
https://github.com/Nexus-Nexx/arctis-nova-pro-oled/issues


QUICK START (no Python needed)
1. Unzip the ArctisOLED folder somewhere permanent (e.g. Documents). Don't run it from inside the zip.
2. Run ArctisOLED.exe. If SmartScreen says "Windows protected your PC": More info -> Run anyway
   (the app isn't code-signed).
3. Play music — the spectrum appears on the base. The window shows a live preview.
4. Pick a visualization and press "Apply to base".
5. ⚙ Settings: language, tray, start with Windows.

Closing the window hides it to the tray (yellow bars icon; on Windows 11 it may sit under the ^ arrow).
Quit: right-click the tray icon -> Exit. The base display keeps running; stop it with the Stop button.

Problems? Run "ArctisOLED.exe --diag" and attach diag.txt to an issue on GitHub.
